# Grafos en Python

Este proyecto implementa las representaciones y operaciones básicas de grafos usando únicamente funciones, listas y diccionarios de Python.

## Ejecutar

```bash
python grafo.py
```

## Incluye

- Representación por diccionario de listas
- Construcción de matriz de adyacencia
- Agregado y eliminación de vértices y aristas
- Consulta de vecinos y existencia de conexión
- Soporte para grafos ponderados con costos directos

## Ejemplo principal

El archivo `grafo.py` contiene ejemplos para:

1. Crear y mostrar un grafo no dirigido
2. Construir la matriz de adyacencia
3. Agregar vértices y consultar vecinos
4. Eliminar aristas y vértices
5. Consultar costo directo en grafos ponderados
